# Hermes Agent 小红书 30 天人设计划

## 一、账号人设

**定位：把复杂 AI Agent 讲成人话的实践型开发者。**

不是“什么都懂的 AI 大师”，而是持续公开记录：

- 我正在如何理解和使用 Hermes Agent
- 一个 Agent 怎样连接模型、工具、记忆和执行环境
- 实验结果、失败案例与工程取舍

### 账号一句话

> 正在把 AI Agent 做成真正能工作的工具，用图解、实测和踩坑讲清复杂 AI。

### 固定栏目

1. **Agent 拆解**：解释架构、概念和术语
2. **开发现场**：展示正在做的事情、代码和决策
3. **Agent 实验室**：一个问题、一次实验、一个结论
4. **失败复盘**：记录没有成功的尝试
5. **一图看懂**：像素图、ASCII 图和流程图

## 二、从两张图提炼的视觉系统

### 核心配色

| 用途 | 颜色 | Hex 参考 |
|---|---|---|
| 科技主色、标题、重点框线 | cobalt blue | `#0B4EAD` |
| 深色背景、网格、正文底 | charcoal | `#202224` |
| 纸张感背景、人物卡片 | warm ivory | `#E8D6B8` |
| 线稿、次级文字 | graphite | `#615850` |
| 强调标签、警告、实验结果 | coral peach | `#D99A86` |
| 主体文字 | soft white | `#F7F0E2` |

### 视觉规则

- **技术图**：深灰底 + cobalt blue 方块 + 细网格。
- **人物/观点图**：米白底 + 铅笔灰线稿 + 一处蓝色标签。
- **人物封面**：使用真人照片，叠加 20%–35% 的 cobalt blue 像素遮罩；保留眼神或侧脸细节，避免完全遮住五官。
- **封面固定元素**：左上角栏目名，右下角编号 `DAY 01`。
- **每张图只保留一个重点色**，避免同时使用过多高饱和色。
- 像素图负责“识别度”，手绘人物负责“亲近感”。

### 真人封面使用节奏

- 每周 3 次真人封面：周一建立主题、周三展示现场、周日总结。
- 其余内容使用架构图、ASCII 图或局部手部/屏幕照片。
- 真人照片保持同一组光线和构图：半身、侧脸或看屏幕，形成连续的“开发者日志”印象。

### 建议封面模板

## 四、每周执行方式

### 周末集中准备

- 选出下周 7 个问题。
- 每个问题先写一句结论。
- 画 2 张像素图，准备 1 张人物/线稿图。
- 统一生成标题、正文和标签。

### 每天发布前检查

- 开头 2 行是否能让非程序员看懂？
- 是否只有一个核心观点？
- 是否有真实例子或可验证的观察？
- 图片文字在手机上是否清晰？
- 是否避免“绝对化”“万能”“颠覆”等夸张词？

### 每晚记录

只记录 3 项：

1. 哪个标题带来最多停留？
2. 哪个解释收到最多评论？
3. 读者下一步还想知道什么？

## 五、目标与复盘指标

不要只看粉丝数，先看内容是否形成记忆点：

- 30 天完成 30 条，至少 4 个固定栏目。
- 每周至少 1 条真实实验或失败复盘。
- 评论区出现“看懂了”“想看下一期”。
- 读者能用一句话复述你的定位。
- 第 30 天形成 3 个可长期连载的主题。

### 评论区固定回复方式

- 先回答问题。
- 再补充一个具体例子。
- 最后反问：“你更想看工具、记忆，还是多 Agent？”

这样可以把评论自然变成下一个选题，而不是单向发帖。
